# Logo „Ring-M“

Das „M“ im Fortschrittsring – derselbe Ring wie im Tagebuch der App.

| Datei | Zweck |
|---|---|
| `logo.svg` | Vorlage (Vektor, 100 × 100) |
| `icon-512.png` | Icon für den Google Play Store / F-Droid |

Farben: Waldgrün `#1F4D3A`, Ring Creme `#F4F1EA` → Gold `#C9A54C`, „M“ Weiß.

In der App (Android): `app/android/app/src/main/res/`
- `mipmap-anydpi-v26/ic_launcher.xml` – anpassbares Icon (Hintergrund + Vordergrund + einfarbig für Android 13+)
- `drawable/ic_launcher_foreground.xml`, `drawable/ic_launcher_monochrome.xml` – Vektoren
- `drawable/ic_notification.xml` – Symbol für Benachrichtigungen
- `mipmap-*/ic_launcher.png` – Rastergrafiken als Rückfall
